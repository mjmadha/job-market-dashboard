# Global Job Market Reality Dashboard

A dark-themed dashboard showing the current global job market.

## Features
- Global unemployment stats
- Youth unemployment insights
- Reality-based messages
- Simple and fast (no framework)

## Deploy

### GitHub
1. Upload files
2. Enable GitHub Pages

### Cloudflare Pages
1. Connect GitHub repo
2. Deploy with default settings

## Note
This project is informational and aims to raise awareness, not discourage users.
